# Alvearium Site

Static public website for Alvearium.

The site presents the project's architecture, prototype and long-term vision. Keep published claims aligned with the current implementation in [the main repository](https://github.com/DerekWiner/alvearium).

## Content policy

The website should distinguish:

- **Prototype** — behaviour that can be run from the current repository.
- **Specification** — documented designs that are not yet implemented.
- **Vision** — longer-term goals such as decentralised agent coordination and post-scarcity systems.

Do not describe identity verification, production sandboxing, payment processing, secure decentralised execution or cross-chain governance as operational unless there is a current implementation and evidence to support the claim.

## Deployment

This repository is configured for GitHub Pages. Check the repository's Pages settings and any configured domain before changing deployment structure.

## Maintenance

Update the homepage and linked pages together. Preserve historical manifestos, but label vision documents where they describe capabilities that are not yet implemented.
